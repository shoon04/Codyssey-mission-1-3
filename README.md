피드백

잘된 점: [직접 써 보니 좋았던 것]
등급에 대한 구분이 색깔로 명확히 구분되어있어 명료하다. 
한정된 영화가 아닌 추가가 가능하다는 점이 좋다. 
초기화를 원할 때 처음으로 버튼을 통해 편하게 초기화가 가능한 부분이 좋다. 

고치면 좋을 점
저장 기능이 없다. 내가 분류한 표가 새로고침하거나 창을 닫았다가 다시 키면 초기화가 된다. 창을 새로고침하거나 창을 닫았다가 켜도 해당 디바이스 한정해서는 저장되었으면 좋겠다. 
창을 축소하면 표가 잘린다. 오른쪽 부분이 잘려 작은 창에서는 표를 활용하기 힘들다. 작은 창에서도 표가 자동으로 축소되어 활용하기 편리했으면 좋겠다. 
빈 제목을 추가하는걸 막았으면 좋겠다. 기능적으로는 오류가 없지만, 추가 버튼을 실수로 눌렀을 때 굳이 추가가 될 수 있으니 해당 기능을 수정하면 좋겠다. 
영화 포스터를 연동할 수 있으면 훨씬 보기 좋을 것 같다.
